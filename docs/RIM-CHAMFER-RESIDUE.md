# 盖板嵌入边顶端倒角「残余模型」根因分析

> 现象：盖板顶端突出部位（嵌入边顶端）倒角后，在对角角落位置出现残余模型。
> 结论先行：**病灶找到并复现，是切割体与嵌入边的「完全共面外壁 + 零宽刀口」导致的
> JSCAD 布尔分类失稳**；默认参数下恰好干净，换尺寸就可能出现，出现位置随参数漂移
> ——这就是为什么它看起来「出现在对向角落」。

---

## 1. 排查过程（怎么找到病灶的）

| 步骤 | 方法 | 结果 |
|---|---|---|
| 1 | 按角度分箱量测每圈切削深度（720 箱 × 3 个高度） | 出现「45°/135° 不切、225°/315° 切 3mm」的假不对称 |
| 2 | 二分定位：嵌入边本体 → +螺孔 → +倒角 → 完整 lid，四角花瓣尖半径 | 四角对称，排除工序错位 |
| 3 | 决定性验证：`residual = final ∩ tool`（成品∩切割体应为空） | 默认参数 = 0，倒角数学上干净 |
| 4 | 高精度差分图（0.1mm 体素，`#`=都有 `.`=被切 `X`=残余） | 默认参数 NE/SE 角、直边两侧全部 X=0 |
| 5 | **参数包络扫描 26 组**，每组成品∩切割体 | **4 组出现残余**，全部在 rounded（关螺丝）轮廓 |
| 6 | 邻近尺寸复扫 20 组 | 又 4 组复现 → 确认「混沌分布」特征 |

## 2. 病灶（两个，叠加）

### 病灶 ①：切割体外壁与嵌入边外壁**严格共面**

`topChamferTool`（`utils.ts`）：

```ts
const slab = outline(l, w, cc);        // ← 与嵌入边完全相同的轮廓、完全相同的位置
...
return translate([0, 0, slabZ], subtract(slab, keep));   // 楔环 = slab − keep
```

楔环的外壁就是嵌入边的外壁——**同一轮廓函数、同一细分段数、同一位置**，
两块实体共享成千上万张完全共面的面片。JSCAD 的 BSP 对「恰好落在切割平面上的面片」
分类结果取决于布尔树的结构——**同一配置下确定性，但换一组尺寸就换一种混沌**。
这正是本项目记忆里的血泪规则「切割体与被切对象共面必留残渣」；当年 planB 线的
`CHAMFER_TOOL_EXPAND`（外移 0.01mm 打破共面）就是为这类问题发明的，
**现行剪切求交版 `topChamferTool` 把这个补偿弄丢了**。

### 病灶 ②：楔环底部是**零宽度刀口**

楔环在 z = slabZ（嵌入边顶端以下 c 处）宽度收敛到 0——一条「刀口」悬在实体内部。
刀口 + 共面叠加，产生退化几何。复现的微粒恰好落在 z=5.60–5.61（= 刀口高度）。

### 复现实测（成品 ∩ 切割体 的残余体积）

| 配置 | 残余 | 位置 |
|---|---|---|
| **50×40.5，关螺丝** | **0.0585 mm³** | bbox 横跨 x[2.4,47.6]、y[2.1,37.1]，z 占满整个楔环高度 → **一整圈贴壁薄片** |
| 60×50，关螺丝 | 0.0011 | x=2.39（min-x 边中点外壁） |
| 50×40，关螺丝 | 0.0036 | x=47.95、y=35.0、z=5.60（刀口高度） |
| 48×42 / 52×38 等邻近尺寸 | 0 | 干净 |
| 默认（100×80，clover/rounded）及 20+ 组 | 0 | 干净 |

特征完全符合「布尔混沌」：**是否出现、出现在哪条边、多大面积，都随尺寸漂移**。
薄片厚度实测 ~0.02–0.06mm，贴着嵌入边外壁立在倒角带上。

### 为什么看起来像「对向角落」

残余出现的位置是混沌的——这一刀切干净了，对角/对边却留下一小条贴壁薄片；
在 3D 预览里就是「倒角切到了这里，对面角落多出一块残余」。另外 clover 轮廓
（开盖板螺丝时）的缺口两瓣**相向而对**（对向），薄片若断在缺口曲率变化处，
视觉上正好落在「对向的角落」。

### 已否证的可能

- 螺丝孔位错位 / 孔切到嵌入边：孔心距嵌入边外壁尚有 ~4mm，无交互；
- 卡扣凸起（union 在倒角之后）：默认关闭，且位置在墙中段非角落；
- 倒角顺序问题：二分显示四角对称；
- 顶面共面（工具顶面 = 嵌入边顶面）：实测把工具向上延伸 0.3mm，残余**逐位不变** → 否证；
- 上游差异：**上游 1.6.1 的 `chamfer.ts` 与本分支逐行相同**，同样存在此隐患。

## 3. 修复方案对比（实测数据）

对复现配置分别试了三种修法，残余体积（mm³）：

| 方案 | 50×40.5 | 60×50 | 50×40 | 100×80(r) | 100×80(clover) | 评价 |
|---|---|---|---|---|---|---|
| 现状 | 0.0585 | 0.0011 | 0.0036 | 0 | 0 | 混沌 |
| **A. 外壁外移 0.01**（rounded 限定） | **0.0010** | 0.0027 | 0.0029 | 0.0095 | 不适用 | 最坏情况 ↓6~60×，但非归零 |
| B. 工具顶面向上延伸 0.3 | 0.0585 | 0.0011 | 0.0036 | 0 | 0 | **无效**（否证顶面共面假说） |
| **F. 工具轮廓改 64 段细分** | **0.0048** | 0.0015 | 0.0021 | 0.0041 | **0.0189（变差）** | rounded 有效、clover 反而变差 |

关键认识：**所有「挪位置」的做法都在重新洗牌混沌**——只要楔环外壁必须贴着嵌入边
外壁（倒角要切到最边缘，这是几何上绕不开的），JSCAD 的 BSP 就总有某个
0.001–0.06mm³ 级的失稳概率。能做的是**压低最坏情况 + 兜底检测**，不是确定性归零。

## 4. 供决策的方案

### 方案一（推荐）：A + 护栏，改动 ~10 行

1. `topChamferTool` 增加可选的 `expand` 参数：**rounded（凸）轮廓传 0.01**，
   slab 按 `outline(l + 2e, w + 2e, cc)` 放大、调用处以 `translate([ri − e, ri − e, 0])` 补偿
   （恢复历史上 `CHAMFER_TOOL_EXPAND` 的做法；倒角深度只浅 0.01mm，占 0.4mm 的 2.5%，不可感知）；
   **clover（凹）轮廓传 0**——凹轮廓外移是本项目验证过的爆炸源（近共面会让 BSP 整片丢面），
   且 clover 实测 26 组全干净，保持现状。
2. `verify-rim-chamfer.cjs` 增加断言：对一组包络配置（含 50×40.5、60×50、50×40 三个复现点）
   检查 `final ∩ tool ≈ 0`，防回归。

- 优点：改动小、有先例、最坏情况压低一个数量级；clover 零风险。
- 缺点：**不保证归零**（个别配置残余可能仍在 0.003–0.01 mm³ 级，均为显微镜级薄片）。

### 方案二（更彻底，改动中等）：出口薄壳清扫

在 `lid()`/导出前加一步「贴壁薄片检测」：`residual = intersect(result, tool)`，
非零则把这些残渣面片从结果中显式减去（或对 result 补一刀外扩工具）。
优点：不依赖布尔运气；缺点：每个实体多两次布尔，且「仍与主体相连的皮」要用
面片级判断（面积/体积比）才能识别，实现和验证成本中等。

### 方案三（最省事）：只加护栏不改几何

仅做 verify 断言 + 在 README 已知问题里记录。适合「残余实际没打到模型上」的判断。

## 6. 用户个例复核（2026-10-15，enclosure-202610159561.json + 截图）——**结论反转**

用户提供了实际参数与截图。关键参数：`lidTopChamfer: 3`、`waterProof: false`、
`lidScrews: true`、`lidScrewHoleType: "through"`、`insertThickness: 2`。

### 排查结果：几何完全干净，薄片不是布尔残渣

| 检查 | 结果 |
|---|---|
| 实际倒角尺寸 | `min(3, 0.9×4, 0.8×2) =` **1.6mm**（被厚度上限夹住；用户填 3 只是触顶） |
| `final ∩ tool` | **0** —— 楔环覆盖区没有任何未切材料 |
| 差分图（0.1/0.25mm 体素，3 个高度） | 45° 倒角正确跟随轮廓，**包括缺口凹弧**，无 X 体素 |
| STL 连通分量 | **单一分量**，体积 18134mm³，无游离碎片 |
| STL 非流形 | 949/4044 = 23.5%，与基线 22% 同量级，无新增病态 |

### 薄片的真实身份：**缺口凹弧上的倒角斜面本身**

开盖板螺丝时，嵌入边走 clover 轮廓——四个角有螺丝柱让位缺口（凹弧）。
倒角沿**整条外缘**生成，缺口凹弧也是外缘的一部分，所以凹弧上同样切出一条
**宽 1.6mm、沿弧延展约 7~10mm 的 45° 曲面带**。

- 默认 `lidTopChamfer=0.4` 时这条带只有 0.4mm 宽，视觉上是一条细线；
- 用户填 3（触顶到 1.6）后，这条带**宽了 4 倍**，从内侧面看就是一个
  「架在缺口上、边缘悬空的薄片」——正好落在缺口（对向角落）位置；
- 它是**真实且按设计生成的几何**（整个外缘都要插进基座槽，缺口弧的斜面同样是 lead-in），
  与第 2 节的共面残渣是**两回事**。

自验方法：把「嵌入边顶端倒角」调回 0.4，薄片应缩成细线；调 0 则消失。
若它不随倒角值连续缩放，再回来找我——那才说明另有问题。

### 处理选项（更新）

| 选项 | 内容 | 评价 |
|---|---|---|
| a. 保持现状 | 几何正确、功能成立（缺口弧的斜面也是插入导向），只是视觉上像薄片 | **推荐**，零改动 |
| b. 收紧上限 | `lidTopChamferSize` 的厚度系数 0.8 → 0.5（t=2 时上限 1.0mm），斜面变窄 | 一行改动，但治标 |
| c. 缺口弧不倒角 | 需在轮廓上区分凹弧段并断开倒角，花瓣尖会出现倒角突变 | 改动大，效果可能更差，不推荐 |
| d. 渲染改善 | 给斜面描边/调光照，消除「悬浮」观感 | 独立改进项 |

第 2 节的共面残渣问题（rounded 轮廓、显微镜级薄片）**仍然成立**，与本个例无关，
方案一（外移 0.01 + verify 断言）仍建议择机实施。
