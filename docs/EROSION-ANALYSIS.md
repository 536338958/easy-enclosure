# 切片异常（内壁侵蚀 / 顶部封死 / 空洞）根因分析

用户在 BambuStudio 中发现（wall=1.5 + 防水 + 螺丝 + 侧面开孔）：

- 内壁异常渲染，**四角尤为明显**
- 切片后**顶部封死**，封死高度与异常区域一致
- 警告「模型在 18 和 20.22 之间出现空洞」「有错误对象方向」

**无开孔的对照模型同样异常** → 与开孔无关。

## 定位手段

`stl-manifold-check.py`（本目录）：统计 STL 非流形边（不被恰好 2 个三角形
共享的边）及其空间分布。切片器的「空洞 / 方向错误 / 封死」全部是非流形边的症状。

## 实测

用户参数（wall=1.5 → _wall=5.08，relief=screwOffset=2.99，槽宽 t=2.08）：

| 模型 | 非流形边 |
| --- | --- |
| base（有孔） | 1019（重叠 5） |
| base（无孔） | 1018 |
| insertClearance 0.04→0.30 | 1019 → 905（间隙只是次要因素） |

位置分布：**z=30 顶部边缘 ~600 条**（→「顶部封死」）、**z=24 槽底 ~330 条**、
**四个角各 40–70 条**（→「四角尤为明显」）、z≈20（→「空洞 18~20.22」）。

### 隔离实验（逐步加减法体）

| 组合 | 非流形边 | 增量 |
| --- | --- | --- |
| 外壳 − 内腔 | 6 | 基线，几乎干净 |
| − 螺丝孔 | 70 | +64 |
| **− 密封圈槽** | **910** | **+840 ← 主犯** |
| − 底部倒角 | 910 | +0 |
| + 挂耳 | 990 | +80 |
| （槽单独，无螺丝孔） | 622 | 槽本身 +616 |

布尔顺序（逐个减 vs 合并减）、间隙大小、螺丝孔直径/位置偏移均只影响 ±50 条，
不是根因。

## 根因：cloverFrame2d 的内外凹弧在四角相交

密封圈槽 = `cloverFrame(l, w, h, t, relief)`。上游实现是「内轮廓 = 长宽减 2t +
平移 t，凹弧半径不变」：

- 外轮廓凹弧：圆心局部 `(r, r)` = (2.99, 2.99)，R = 2.99
- 内轮廓平移后凹弧：圆心 `(t+r, t+r)` = (5.07, 5.07)，R = 2.99
- 圆心距 = √2·t = **2.94 < R = 2.99** → 两条凹弧**必然相交**

两条相交的凹弧把四角的框材料切成近乎断裂的「残鳍」，JSCAD 布尔在这些交点处
产生病态分类 → 每角几十条非流形边 × 槽的整个高度（z 24~30）。

这正是旧分支 CHANGELOG TODO 记录过的：
> 凹弧处壁厚仍会不均匀（凹弧内缩时半径未相应增大）……顶环在凹弧 S 弯处可能
> 收窄出残鳍，需专门用 true offset（凹弧半径 r+t）修复。

旧分支曾把 clover2d 重写为解析式（圆心/半径解耦）以支持真等距内缩，
**回滚时丢失**，只剩 TODO 注释。

内腔本身（`clover` 实体，非框）轮廓完好（不自交、闭合、最短边 0.39mm），
所以「外壳 − 内腔」只有 6 条非流形。

## 修法（阶段 4，需扩容）

1. **重写 `clover2d` 为解析式**：直边 + 圆弧解析拼接（圆心与半径解耦），
   替换现在的「布尔拼 4 角圆 + 8 个过渡件」
2. **`cloverFrame2d` 改真等距内缩**：直边内缩 t，**凹弧半径 r+t、圆心不动**
   → 内外轮廓同构、间距恒为 t，残鳍消失
3. 同族缩放语义对 roundedCube/roundedFrame 不变（它们没有凹弧问题）
4. 验收判据：`stl-manifold-check.py` 非流形边 < 10（基线 6）；npm run verify 全过

改完后槽、盖板嵌入边（同为 cloverFrame）一并修复。
