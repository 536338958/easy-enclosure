# Easy Enclosure 简易外壳设计器

![](public/screenshot.png)

EasyEnclosure 是一款开源的 3D 建模软件，专门用于设计可 3D 打印的外壳。它力求提供直观的界面和
一套简单易用的控件，让即使没有或几乎没有 3D 建模经验的人，也能为自己的电子项目、原型或
DIY 小装置制作定制外壳。

> 本仓库基于 **v1.4.2** 稳定基线持续开发（该版本错误较少、可实际使用），在此之上逐轮叠加
> 功能与修复；当前版本号 **v1.6.1**（与上游对齐以便对照，**代码内容是 v1.4.2 + 本分支自有迭代**，
> 不等于上游 1.6.1）。上游原版见
> [bruceborrett/easy-enclosure](https://github.com/bruceborrett/easy-enclosure)。

## 主要特性

### 基础功能

- 实时 3D 预览，参数改动即时反映
- **导出 STL 与 STEP 两种格式**：可勾选部件，多个文件自动打包成 ZIP
- 以 JSON 形式保存和加载参数预设（**旧预设无需迁移，新字段全部有兜底**）
- 圆形 / 方形 / 长方形开孔，可放置于任意面
- 防水结构（双层壁 + 密封圈槽）
- 盖板螺丝固定、壁挂挂耳与 DIN 导轨挂夹
- 卡扣盖 Snap-Fit：4 / 6 / 8 个卡扣预设，免螺丝闭合

### 交互体验

- **中英文双语界面**：侧边栏顶部下拉菜单切换，全站文案即时生效；默认「跟随系统」按浏览器语言自动选择
- **参数说明气泡**：每个参数标签带叹号，悬停显示含义、单位与方向，面板不再拥挤
- **0=自动 的参数显示当前生效值**：如「0＝自动，当前生效 3.24 mm」，改参数时实时更新
- **XYZ 坐标轴显示**：网格中可开启坐标轴（X 红 / Y 绿 / Z 蓝），对照各偏移方向
- **PCB 预览 + 实时碰撞检测**：放入虚拟 PCB，与侧壁 / 隔板 / 线缆夹 / 盖板碰撞时红色高亮，
  提示栏同时显示**重叠体积**（如「超出 12.4 mm³），无碰撞为绿色

### 几何能力

- **散热通风四种模式**：长条槽（**0–180° 任意角度**）/ 圆孔网格 / 方孔网格 / **六边形蜂窝**，
  网格模式支持列数 × 行数；**开孔范围**（第 17 轮新增）：可设水平/竖直范围（0 = 整面），
  开孔只在范围内生效，压线的裁出平头
- **PCB 支柱与内隔板**：自定义位置、高度、螺丝孔，划分内部空间；支柱根部圆角 / 斜角降低应力集中
- **线缆夹**：走线夹 + 配套压条，可放任意面、可调柱距 / 鞍座高 / 夹体厚 / 旋转角，带防脱肋条
- **开孔孔型二选一**：透孔 / 不透孔（深度由外壁向内、自动夹紧不打穿）；
  方孔 / 矩形孔还可开启**孔口 45° 导入倒角**（圆孔因性能原因不提供倒角）
- **基座螺丝孔型三选一**：贯穿孔 / 盲孔（可设深度，保证不打穿底板）/ 嵌入螺母槽
- **盖板螺丝孔位与螺丝柱凸出量可调**（均支持 0=自动）
- 倒角体系：底边 45° 倒角（缓解首层「象脚」，同步应用到挂耳）、嵌入边顶端导入倒角；
  挂耳切角角度可调（45–70°）
- **盖板螺丝沉头窝三选一**：无 / 圆柱沉头窝（平底，可设直径与深度，把螺栓头整颗藏进盖板）/
  45° 锥坑（配沉头螺丝，深度由窝口直径与孔径之差算出）；深度自动夹紧，不会打穿盖板本体
- 偏移方向统一约定：所有开孔 / 支柱 / 隔板 / 通风槽 / 线缆夹的 X / Y 偏移，
  `+` 始终指向 +世界轴，标签按所在面动态取名

## 质量保障

- **288 个单元测试**（`npm test`）：覆盖通风四模式、线缆夹、PCB 预览与碰撞检测、倒角、尺寸等
- **几何验证脚本**（`npm run verify`）：秒级检查挂耳切角、内腔地板、嵌入边倒角闭合、
  盖板装配间隙与 3D 干涉，无需起浏览器
- **STL 流形检查工具**（`docs/stl-manifold-check.py`）：统计非流形边并定位，
  是排查切片软件「空层 / 破面 / 对象方向错误」的金标准

已知边界：当前版本的几何在 CAD 软件（如 FreeCAD）中打开可能提示「未闭合」，
但切片软件（BambuStudio 等）实测可正常切片。相关基线数据记录在
`docs/baseline-before.txt`。

## 技术栈

TypeScript、Angular、JSCAD

## 开发

### 环境要求

- Node.js 20+
- npm 10+

### 安装依赖

```bash
npm install
```

### 本地运行

```bash
npm run dev
```

该命令会从仓库根目录启动 Angular 应用，并根据 `package.json` 同步界面上的版本号徽标。

### 构建

```bash
npm run build
```

产物输出到 `dist/angular-app/browser`。

### 测试与几何验证

```bash
npm test          # 单元测试（288 例）
npm run verify    # 几何自检：切角 / 地板 / 倒角闭合 / 装配干涉
```

### 部署到 GitHub Pages

本仓库已内置 GitHub Actions 自动部署工作流（`.github/workflows/deploy-pages.yml`）：
将代码推送到默认分支后，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**，
即可由 GitHub 自动构建并发布，无需在本机执行构建。工作流会按仓库名自动设置 `base-href`。

也可以在本机手动构建并发布：

```bash
npm run deploy
```

## 说明

- 所有尺寸单位均为毫米（mm）
- 用于户外的外壳应使用 PETG 耗材打印
- 防水密封圈应使用 TPU 耗材打印
- 开孔处打印时需要添加支撑
- 总高度 = 底座高度 + 壁厚；内部高度 = 底座高度 − 壁厚
- 内部宽度 = 宽度 −（壁厚 × 2）；内部长度 = 长度 −（壁厚 × 2）
- 螺丝会占用四角的额外空间，在确定长度和宽度时请留意这一点
- 开孔 / PCB 支柱 / 内隔板 / PCB 预览 / 通风槽 / 线缆夹的 X、Y 偏移均以所在面（或底座）
  中心为原点，正方向见界面上各输入框标签，可开启「网格 → 显示坐标轴」对照
